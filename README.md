Personal website and writing archive for Xiaokun Duan.

## What This Repository Is

This repository contains the published static site for `xiaokunduan.github.io`.

It serves as a public-facing home for:

- personal writing
- project notes
- selected work and experiments

## Structure

```text
index.html   homepage (hand-written, five languages)
posts/       published post pages and their images
tags/        tag pages
archives/    archive page
assets/      CSS, JS and avatar
```

Post pages are generated elsewhere and copied here; the homepage is edited directly.
