Personal website and writing archive for Xiaokun Duan.

## What This Repository Is

This repository contains the published static site for `xiaokunduan.github.io`.

It serves as a public-facing home for:

- personal writing
- project notes
- selected work and experiments

## Structure

```text

archives/    archive pages
index.html   site entry
```
